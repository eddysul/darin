## Feature Freeze 버그 분류

### 수정 완료
- **P0** 저장/불러오기 예외를 조용히 무시해 데이터 유실을 알 수 없던 문제
  - 모든 로컬 store에서 공통 storage issue를 발행하도록 수정
  - 공통 오류 배너에 불러오기/저장 실패 문구, 재시도, 닫기 연결
- **P1** 자정 전에 시작한 수면을 다음 날 종료할 수 없던 문제
  - 전날의 진행 중 수면 탐색 및 자정 경과 시간 계산 추가
- **P1** 앱 완전 종료 후 항상 로그인으로 돌아가 복원 플로우가 막히던 문제
  - 저장된 Care Setup이 있으면 hydration 완료 후 메인으로 복귀하도록 수정
- **P2** `formatLog`/카테고리 모듈 순환 참조 런타임 경고
  - 포맷 유틸 직접 import로 순환 제거
- **P1** 일기 알림 테스트가 `· · ·` 숨은 길게 누르기로만 실행되던 문제
  - `알림 테스트` 명시적 버튼과 일반 탭으로 변경
- **P2** 프로필·가족 진입 버튼에 접근성 이름이 없던 문제
  - `아기 프로필 및 가족 관리` 라벨 추가
- **P2** 음성·기록 수정·가족 초대 시트의 바깥 `Pressable`이 내부 입력/버튼을 하나의 접근성 요소로 병합하던 문제
  - 컨테이너를 접근성 그룹에서 제외해 하위 입력·수정·저장·재시도 버튼을 개별 노출
- **P0 예방** hydrate read 실패 뒤 초기/샘플 상태가 기존 저장값을 덮어쓸 수 있던 문제
  - 실패한 store는 hydrated로 표시하지 않고 자동 저장을 차단
  - 공통 배너 재시도 시 storage를 강제 reload해 원본 상태 복구
- **P1** AI 실패 재시도에서 같은 사용자 질문을 다시 채팅에 추가하던 문제
  - 실패 질문을 별도 보존하고 재시도에서는 기존 질문/히스토리를 재사용
  - 동기 in-flight guard로 재시도 중복 입력 차단
