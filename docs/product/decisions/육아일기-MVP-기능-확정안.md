# 육아일기 MVP 기능 확정안

**상태:** Confirmed  
**범위:** 육아일기 1차 MVP (기능 추가 중단 · 확정 문서화)  
**작성일:** 2026-07-17

---

## 1. 핵심 결정

1. **월간 PDF 자동 생성이 아니다.**  
   부모가 선택한 기록을 모아 **성장책**으로 만든다.

2. **성장책은 일기 기능 안에 포함**된다.  
   별도 탭/제품이 아니라, 일기 작성 → 성장책에 담기 → 책 미리보기 흐름으로 구성한다.

3. **1차 MVP 이후는 기능 확장보다 확정·안정화**를 우선한다.  
   (서버 푸시 스케줄링, 서버 PDF 배송, 고급 3D 책 UI 등은 후속)

---

## 2. 제품 흐름 (Canonical)

```
새 일기 쓰기
  → 사진 / 코멘트 작성
  → 하늘·마음 스탬프 선택 (선택)
  → 성장 순간 태그 선택 (선택)
  → 성장책에 담기 ON/OFF
  → 저장
  → 목록 카드 반영
  → 필터(전체 / 성장 순간 / 성장책)
  → 성장책 보관함
  → 책 미리보기 (페이지 넘김)
```

---

## 3. 확정 기능 범위

### 3.1 일기 작성·저장

| 항목 | 확정 |
|------|------|
| 저장 조건 | 사진 **또는** 코멘트 중 하나 이상 |
| 사진만 저장 | 허용 (코멘트 플레이스홀더 저장, UI에는 부드러운 문구 표시) |
| 코멘트만 저장 | 허용 |
| 오늘 일기 | 날짜당 1개 — 이미 있으면 **수정** (중복 생성 방지) |
| Draft | 의미 있는 입력 시 자동 저장, 닫았다가 이어쓰기 |
| Care Log 요약 | 저장 시점 스냅샷 고정 (수정 시 덮어쓰지 않음) |
| Moment Suggestions | 규칙 기반 제안 → 코멘트에 이어붙이기 |
| 스탬프 | 오늘의 하늘 / 오늘의 마음 — 탭으로 선택·해제 |
| 성장 순간 | 프리셋 태그 또는 커스텀 |
| 삭제 | 일기 삭제 시 성장책에서도 함께 제외 |

### 3.2 목록·필터

| 항목 | 확정 |
|------|------|
| 필터 | 전체 / 성장 순간 / 성장책 — **카운트 표시** |
| 카드 | 사진(없으면 스탬프/아이콘), 날짜, 코멘트, 성장 태그, 담기 칩 |
| 담기/빼기 | 카드에서 즉시 토글 |

### 3.3 성장책

| 항목 | 확정 |
|------|------|
| 담기 방식 | 부모가 선택 (`includedInGrowthBook`) |
| 보관함 | 담은 기록 목록, 빼기, 통계(기록 수·사진 수·예상 쪽수) |
| 미리보기 | 표지 → 기록 페이지(시간순) → 마무리 편지, 스와이프/화살표 넘김 |
| 편집 | 표지·페이지 레이아웃·코멘트·편지 편집본 (`GrowthBookEdit`) |
| PDF | 기기 로컬 생성·공유 (`expo-print`). 서버 배송·자동 월간 생성은 비포함 |
| 자동 월간 생성 | **하지 않음** |

### 3.4 알림 (MVP)

| 항목 | 확정 |
|------|------|
| 형태 | 앱 내 토스트 + 딥링크 (`knanny://diary/compose`) |
| 설정 | 켜기/끄기 + 시각 |
| 열기 규칙 | 오늘 저장됨 → 수정 / draft 있음 → 이어쓰기 / 없으면 새 작성 |
| OS 푸시 | 후속 |

## 4. 빈 상태 (Empty UX)

다음 상태는 **의도된 1차 UX**로 유지한다.

| 상태 | 기대 |
|------|------|
| 일기 없음 | 안내 + 「첫 일기 쓰기」 CTA |
| 성장책 비어 있음 (필터·보관함) | 담기 유도 문구 |
| 사진 없는 일기 | 썸네일 자리 스탬프/아이콘 |
| 코멘트 없는(사진만) 일기 | 「사진만 남긴 하루」 표시 |
| 오늘 Care Log 없음 | 요약 안내 + 「기록이 없어도 일기는 남길 수 있어요」 |
| 알림 off | 「일기 알림 · 알림 꺼짐 · 알림이 꺼져 있어요」 |

---

## 5. 명시적 Non-goals (MVP 밖)

- 월간 PDF 자동 생성·인쇄소 배송
- 서버 OS 푸시 스케줄링
- 서버 PDF 파이프라인
- 2페이지 펼침 / 3D 책 넘김
- 다중 아기·다중 작성자 권한 고도화
- AI 장문 일기 자동 작성

---

## 6. 스키마 요지 (`DiaryEntry`)

- `id`, `babyId`, `date`, `dateKey`
- `photos[]`, `comment`
- `weatherStamp`, `moodStamp`
- `careLogSummarySnapshot`, `momentSuggestionsUsed[]`
- `milestoneTag` / `customMilestoneTag`
- `includedInGrowthBook`
- `createdBy`, `createdAt` / `updatedAt`
- `source`: `manual` | `notification`
- `draftStatus`: `draft` | `saved`

레거시 필드(`photoUri`, `emoji`, `inGrowthBook` 등)는 hydrate 시 마이그레이션.
