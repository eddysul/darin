# MVP 이후 기능

데모에서 **실행 가능한 MVP 기능처럼 설명하지 않는** 후속 범위입니다.

| 기능 | 현재 | 후속 조건 |
|---|---|---|
| 서버 PDF 파이프라인·인쇄소 배송 | 기기 로컬 PDF 생성/공유만 | 서버 렌더·배송 정책 |
| 실기기 OS 푸시 스케줄링 | 앱 내 알림 설정 + `expo-notifications` 권한 흐름 | 백그라운드 스케줄·딥링크 실기기 검증 |
| 서버 가족 초대/실시간 공유 | 초대 코드·상태 로컬 목업 | 인증·백엔드·권한 API |
| 결제 | 미제공 | 요금제·스토어 정책 |
| Apple Watch | 미제공 | Watch 앱 범위 확정 |
| 월간 PDF 자동 생성 | 하지 않음 (부모가 성장책 선택) | 제품 정책 변경 시 |

## 데모 문구 원칙
- 성장책 PDF: **기기에서 PDF 만들기**까지 시연 가능. 서버 배송·자동 월간 생성은 말하지 않음.
- 알림: 앱 내 설정·권한 요청까지. “서버가 매일 푸시한다”고 말하지 않음.
- 가족 초대: `목업 · 실제 전송 없음`
- 결제 / Apple Watch: 화면에 노출하지 않음
