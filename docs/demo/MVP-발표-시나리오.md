# K-Nanny MVP 발표 시나리오

## 준비
- 앱을 완전히 종료 후 다시 열어 AsyncStorage 복원을 확인한다.
- 첫 설치 상태에는 오늘 기록, 최근 7일 기록, 성장책 일기, 가족/시터 샘플이 제공된다.
- 이미 발표 리허설 데이터를 만든 경우 그대로 복원되며, 삭제한 데이터가 샘플로 되살아나지 않는다.

## 고정 플로우 (약 4분)

1. **원터치 수유 기록**
   - 기록 탭 → `분유 120ml` 빠른 기록 탭
   - 완료 토스트와 타임라인 하이라이트 확인
   - 오늘 요약의 수유 횟수 증가 확인

2. **기록 수정**
   - 방금 생성한 토스트 또는 카드 탭
   - 분유량/시간/메모 수정 후 저장
   - 타임라인 표시가 즉시 바뀌는지 확인

3. **음성 기록**
   - 하단 마이크 → 데모 문장 `응가했어 노란색`
   - 전사 결과 카드 확인 → 전체 저장
   - 기록 탭에서 `작성자 · 음성` 출처 확인

4. **일기 작성**
   - 일기 탭 → 새 일기 쓰기
   - Care Log 요약에 방금 기록이 반영됐는지 확인
   - 사진/코멘트, 하늘/마음 스탬프, 성장 순간 태그 선택
   - `성장책에 담기` ON → 저장

5. **성장책**
   - 성장책 필터에서 방금 일기 확인
   - 성장책 보관함 → 미리보기
   - 표지 → 시간순 일기 페이지 → 마지막 편지까지 넘기기

6. **리포트**
   - 리포트 탭 → 오늘 요약과 주간 트렌드 확인
   - 수유/수면/기저귀 상세 카드 진입

7. **AI 상담**
   - 상담 탭 → `오늘 특이한 점 있어?`
   - 참고 정보에 아기 프로필, 오늘 기록, 7일 트렌드, 최근 일기가 표시되는지 확인

8. **가족 공유 목업**
   - 프로필 → 박시터 작성 기록과 역할/상태 확인
   - 초대 코드 생성 및 수락 시뮬레이션 확인

## 데모 안전장치
- 실제 STT가 불가능하면 마이크 화면의 3개 데모 문장을 사용한다.
- API 키/네트워크 오류 시 공통 에러 상태와 재시도를 보여준다.
- PDF, OS 푸시, 서버 초대는 실행하지 않는다. 모두 MVP 이후 범위다.
