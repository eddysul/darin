## 1. 한 줄 요약 (로컬 MVP)

부모가 **빠르게 기록**하고, **일기·성장책**으로 남기며, **한눈에 보기·AI 상담**으로 돌아보는 육아 기록 데모.

**로컬 MVP에 없음 (명시):**
- 서버 DB
- 실제 Apple / Google OAuth
- 실시간 가족 공유·서버 초대
- 결제 / 구독 과금

데이터는 **기기 로컬(AsyncStorage)** 에만 남는다.

---

## 2. 현재 앱 구조 (로컬 MVP)

### 진입 플로우
```text
스플래시
  → (약관 미동의) 약관 동의
  → 로그인 목업 (Apple / Google / 이메일 UI · 실인증 없음)
  → 온보딩 (나 → 아기 연결 → 아기 정보 → 돌봄 설정 → 확인)
  → (가족 공유 ON 시) 초대코드 화면 (로컬 목업)
  → 메인
```

Care Setup이 이미 저장된 기기는 `스플래시 → 메인`으로 복원한다.

메뉴 **로그아웃**: Care Setup을 지워 로그인/온보딩으로 되돌린다.  
기록·일기 등 로컬 데이터가 남는 동작은 **데모 편의용**이며, 서비스형 계정 삭제/동기화 정책이 아니다.

### 하단 메인 탭 (5개)
| 탭 | 역할 |
|----|------|
| **기록** | 원터치·빠른 기록, 롱프레스 타이머/상세, 오늘 요약, 타임라인 |
| **일기** | 육아일기 작성·필터, 성장책 담기, 알림 설정 진입 |
| **음성** | 음성 → 다중 이벤트 확인·저장 (중앙 마이크) |
| **한눈에** | 오늘 요약·주간 트렌드·카테고리 상세 |
| **메뉴** | 프로필·가족·스티커·알림·약관·로그아웃 |

### AI 상담 (탭 아님)
- 하단 탭이 아니다.
- **기록 화면의 floating 버튼(AI 상담)** 으로 진입한다.
- Care Log / 일기 등 로컬 컨텍스트 + OpenAI(키 있을 때).

### 온보딩 (사용자에게 보이는 3단계)
1. **나에 대해** — 이름, 관계(엄마/아빠/보호자/가족/시터), 임신·산후, 언어  
2. **아기 정보** — 새 아기 등록 **또는** 초대코드 연결 → 출생 여부 분기 → 필수 최소 입력  
3. **돌봄 설정** — 기본 수유, 표시 카테고리, 가족 공유 → 확인 → 시작  

관계는 가족 멤버·성장책 작성자 표시에 `엄마 민지` 형태로 저장된다 (로컬).

## 3. 발표 준비

- 앱을 **완전히 종료 후 재실행**해 로컬 복원을 한 번 확인한다.
- 신규 온보딩을 보여줄 때는 메뉴에서 **로그아웃**(데모 편의) 후 진행한다. 약관은 이미 동의한 기기면 로그인 목업부터.
- **OpenAI 키가 있으면** AI 상담 실응답 데모.  
  **키가 없으면** 에러 상태 + 재시도 UX만 보여줘도 데모 가능하다.
- STT 서버가 없으면 음성 탭의 **데모 문장**을 쓴다.
- 초대코드 데모(로컬 목업): `DARIN1` / `KNANNY` (또는 임의 6자리)

---

## 4. 고정 데모 플로우 (약 5–6분)

### A. 온보딩 (신규, ~90초)
1. 약관 — 필수 3개 체크 → 동의하고 시작하기  
2. Apple(또는 Google)로 계속하기 — **실 OAuth 아님(목업)**  
3. 나에 대해 — 이름·관계  
4. 새 아기 등록 → 태어났어요 → 이름·생년월일 (사진 등은 선택)  
5. 돌봄 설정 → 확인 → **시작하기** → 메인  

> 초대코드 조인 목업: 연결하기 → `DARIN1` → 확인 → 메인.

### B. 원터치 기록
1. **기록** 탭 → 분유 **짧게 탭** → 즉시 생성 (바텀시트 자동 오픈 없음)  
2. 토스트·타임라인·오늘 요약 확인  
3. (선택) 모유 **길게 누름** → 타이머 → 종료·진행 중 표시

### C. 기록 수정
1. 토스트 또는 타임라인 카드 → 양/시간/메모 수정 → 즉시 반영

### D. 음성
1. **음성** 탭(중앙 마이크) → 데모 `응가했어 노란색`  
2. 저장 → 타임라인에 `작성자 · 음성` 출처

### E. 일기 · 성장책
1. **일기** → 새 일기 → Care Log 요약 확인  
2. 저장 시 성장책 담기 ON  
3. 성장책 미리보기/편집 → **PDF 만들기**: 기기 내 **고정 템플릿** 생성·공유까지만 (서버 배송·자동 월간 생성 없음)

### F. 한눈에 · AI · 가족
1. **한눈에** — 오늘 요약·주간 트렌드  
2. **기록** 화면 floating **AI 상담** — `오늘 특이한 점 있어?` (키 없으면 에러/재시도 UX)  
3. **메뉴** — 가족 역할·초대 목업, 로그아웃(데모 편의) 위치

## 5. 로컬 MVP에서 데모 가능한 것

| 영역 | 내용 |
|------|------|
| 온보딩 | 약관, 로그인 목업, 3단계, 출생 분기, 초대코드 조인 목업, Safe Area |
| 기록 | short tap / long press 타이머·상세, 진행 중 복원, 오늘 요약·타임라인 |
| 음성 | 녹음·전사 또는 데모 문장, 다중 이벤트 |
| 일기 | 작성·draft·스탬프·태그·Care Log 스냅샷·알림 설정 UI |
| 성장책 | 담기·미리보기·편집·스티커, **기기 고정 템플릿 PDF 생성/공유** |
| 한눈에 | Care Log 실집계 오늘·주간 |
| AI 상담 | floating 진입, 로컬 컨텍스트 + OpenAI(키 있을 때) / 없으면 에러·재시도 |
| 가족 | 로컬 멤버·역할·초대 코드·수락 시뮬레이션 |
| 영속화 | 기기 AsyncStorage |
| 메뉴 | 프로필·스티커·알림·약관 안내·로그아웃(데모 편의) |

## 6. 말하지 말 것 (과장 금지)

발표 중 아래를 **서비스가 이미 된다**고 말하지 않는다.

| 항목 | 로컬 MVP 실제 | 말하지 말 것 |
|------|---------------|--------------|
| Apple / Google 로그인 | UI 목업만 | “계정 연동 완료”, “소셜 로그인 실서비스” |
| 가족 초대 | 로컬 코드·수락 시뮬레이션 | “상대 폰에 실시간 전송·동기화” |
| 푸시 | 앱 내 알림 설정·권한 흐름 | “서버가 매일 푸시한다” |
| PDF | 기기 고정 템플릿 생성/공유 | “인쇄소 배송”, “월간 자동 생성” |
| 결제 | 무료 플랜 안내 문구 | “유료 구독이 동작한다” |
| 백엔드 | 없음 | “클라우드에 저장된다”, “서버 DB” |
| Watch 등 | 없음 | 언급하지 않음 |

8월 말 **서비스형 출시** 로드맵과 겹치면, “그건 출시 전환 문서 범위”라고만 하고 이 데모와 섞지 않는다.

---

## 7. 데모 안전장치

- STT 불가 → **데모 문장**  
- OpenAI 키 없음 → **에러 + 재시도 UX**로도 데모 가능  
- 초대·서버 푸시·PDF 배송·결제·실 OAuth → **실행·약속하지 않음**  
- 로그아웃 후 재온보딩: Care Log가 샘플로 되살아나지 않음 (로컬 빈 저장 유지). 데이터 잔류는 **데모 편의**

## 8. 체크리스트 (로컬 데모)

- [ ] 문서/멘트가 **로컬 MVP 데모**임을 전제함  
- [ ] 하단 탭: 기록 · 일기 · 음성 · 한눈에 · 메뉴  
- [ ] AI 상담 = **floating 버튼** (탭이라고 말하지 않음)  
- [ ] 서버 DB / 실 OAuth / 실시간 공유 / 결제 = 없다고 명확히  
- [ ] PDF = 기기 고정 템플릿 생성·공유만  
- [ ] OpenAI 키 없을 때 에러/재시도로 대체 가능  
- [ ] 「말하지 말 것」 과장 금지  
- [ ] 8월 서비스형 출시 항목과 혼동하지 않음 (별도 문서)
